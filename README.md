# 青春梦工厂首页原型

基于 Vite、React 和 TypeScript 的互动首页。当前版本使用完整地图图作为视觉底图，并通过百分比定位的透明热区实现模块点击、悬停提示、弹窗预览与底部导航反馈。

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 正式构建

```bash
pnpm run build
```

## 当前范围

- 七个地图模块均可点击和键盘聚焦。
- 任务中心展示下一阶段的三个任务分类预览。
- 成长面板、个人信息区和底部导航具有交互反馈。
- 页面按照 1672 × 941 的设计基准等比例适配桌面屏幕。
